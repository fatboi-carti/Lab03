# Итоговые вопросы

Чтобы понять текст, закодированный в байты, нужно знать как он закодирован.

При кодировке компьютер использует определённые правила, которые ему указывает человек. Если нужно закодировать текст, то каждый символ будет закодирован в байт/байты в соответствии с его значением по кодировке. Числа же просто переводятся из десятичной системы и кодируются не посимвольно, а как одно целое. Но если захотеть,то можно перевести кодировку числа в кодировку текста. Компьютер без указаний не знает текст это или просто число.
